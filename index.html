⚙ Configuração Inicial
Para sincronizar entre dispositivos, o app usa o Firebase (gratuito). Configure uma vez e funciona para sempre.
01
Acesse console.firebase.google.com → Criar projeto (grátis)
02
Vá em Firestore Database → Criar banco → Modo de produção
03
Em Configurações do projeto → Seus aplicativos → Web, copie o apiKey e projectId
04
Em Firestore → Regras, cole: allow read, write: if true; e publique
